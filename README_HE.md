# TG Free Hub: בוט טלגרם + Mini App + AI עם מפתחות דינמיים (הכול בחינם)

## מה זה עושה

- **ספריית קבצים**: מחפשים קבצים וסרטונים לפי שם, רואים את המשקל המדויק (MB/GB), ולחיצה שולחת את הקובץ לצ'אט בטלגרם. אין נגן ואין אחסון אצלך.
- **עוזר AI**: צ'אט בתוך האפליקציה ובתוך הבוט. אפשר גם לבקש ממנו "תמצא לי את הדוח של המס" והוא יריץ חיפוש בספרייה.
- **מנהל מודלים חכם**: מסך ניהול באפליקציה (וגם פקודות בבוט) שבו מוסיפים בכל רגע ספק AI חדש או מפתח חדש, בלי לגעת בקוד ובלי פריסה מחדש.
- **גיבוי אוטומטי בין מודלים**: אם מפתח נגמר או מוגבל, המערכת עוברת למפתח הבא באותו ספק, ואחר כך לספק הבא.
- **אפליקציית אנדרואיד (APK)** מאותו קוד, עם כניסה בקוד חד-פעמי שהבוט שולח.

```
משתמש ──► Telegram ──► Webhook ──► שרת FastAPI (Render, חינם)
                │                        ├─ SQLite: אינדקס קבצים + ספקים/מפתחות (מוצפנים)
 Mini App / APK ┴──► /api/* ◄────────────┤
                                         └─ נתב AI: Gemini → Groq → Cerebras → OpenRouter → ... (כמה שתוסיף)
הקבצים עצמם נשארים בטלגרם. השרת שומר רק מזהים.
```

## למה אין צורך ב-Pyrogram או Telethon

הבוט **לא מעלה קבצים מחדש**. הוא מעתיק הודעה קיימת (`copyMessage`) או שולח `file_id` קיים. שתי הפעולות עובדות גם לקבצים של 2GB, והשרת לא מוריד ולא מעלה בייט. מגבלת ה-50MB של Bot API חלה רק על העלאה של קבצים חדשים מהשרת, וזה לא מה שקורה כאן.

הדרך להכניס קבצים לספרייה: להעלות אותם לטלגרם **ידנית** (מהטלפון או מהמחשב, בלי מגבלת הבוט), ואז להעביר אותם לבוט או לערוץ שהבוט מנהל. פרטים בשלב 6.

> השתמש בספרייה רק לקבצים שיש לך זכות להפיץ או לשמור.

## שלב 1: מה צריך להכין (הכול בחינם)

1. חשבון טלגרם.
2. חשבון [GitHub](https://github.com).
3. חשבון [Render](https://render.com) (אפשר להירשם עם GitHub).
4. לפחות מפתח AI אחד. הכי קל להתחיל עם Gemini: [aistudio.google.com/apikey](https://aistudio.google.com/apikey). את השאר אפשר להוסיף מאוחר יותר מתוך האפליקציה.

## שלב 2: יצירת הבוט ב-BotFather

1. בטלגרם חפש **@BotFather** (עם וי כחול) ושלח `/newbot`.
2. בחר שם תצוגה (למשל "הספרייה שלי") ושם משתמש שמסתיים ב-`bot` (למשל `my_hub_123_bot`).
3. BotFather שולח **Token** בצורה `123456789:AAH...`. שמור אותו. זה `BOT_TOKEN`.
4. חפש **@userinfobot**, שלח לו הודעה, והוא יחזיר את **המזהה המספרי שלך**. זה `ADMIN_IDS`.
5. (לא חובה) ב-BotFather: `/setdescription` ו-`/setuserpic` לעיצוב.

את כפתור התפריט (Mini App) ואת רשימת הפקודות השרת מגדיר לבד בהפעלה, אין צורך בהגדרה ידנית.

## שלב 3: העלאה ל-GitHub

1. צור repository חדש ופרטי בשם `tg-free-hub`.
2. העלה אליו את כל התיקייה הזאת (גרור וזרוק בממשק האתר, או `git push`).
3. **אל תעלה קובץ `.env`**. הוא ברשימת ה-`.gitignore`.

## שלב 4: פריסה ב-Render

1. ב-Render: **New +** ← **Web Service** ← חבר את ה-repository.
2. Runtime: **Docker** (ה-`Dockerfile` כבר קיים). Plan: **Free**.
3. תחת **Environment** הוסף:

| משתנה | ערך |
|---|---|
| `BOT_TOKEN` | ה-Token מ-BotFather |
| `ADMIN_IDS` | המזהה המספרי שלך |
| `SECRET_KEY` | מחרוזת אקראית ארוכה (30 תווים ומעלה). **שמור אותה במקום בטוח**, בלעדיה אי אפשר לפענח גיבויים |
| `PUBLIC_URL` | בינתיים כתוב סתם `https://temp.example.com` |

4. לחץ **Create Web Service** והמתן לבנייה (כמה דקות).
5. כשהסתיים, Render מציג כתובת כמו `https://tg-free-hub-xxxx.onrender.com`. **העתק אותה.**
6. חזור ל-Environment, שנה את `PUBLIC_URL` לכתובת האמיתית (בלי `/` בסוף) ושמור. Render יפעיל מחדש.
7. בהפעלה השרת מגדיר לבד את ה-Webhook, את כפתור התפריט ואת הפקודות.

**בדיקה:** פתח בדפדפן `https://הכתובת-שלך/health`. אמור להופיע `{"ok":true,...}`.

> אפשרות חלופית ל-Render: Koyeb. אותו Dockerfile, אותם משתני סביבה, ובאותו אופן `PUBLIC_URL` הוא הכתובת שהם נותנים.

## שלב 5: הפעלה והוספת מפתחות AI

1. שלח לבוט `/start`. אמור להופיע כפתור **📂 פתח את האפליקציה**.
2. פתח את האפליקציה ← לשונית **ניהול** (מופיעה רק לאדמינים).
3. לחץ **הוסף מודל או מפתח**, בחר ספק (למשל Google Gemini), הדבק מפתח ושמור.
4. לחץ **בדוק חיבור**. אם מופיע ✔ הכול עובד.
5. חזור על זה לכל ספק שתרצה: Groq, Cerebras, OpenRouter, Hugging Face ועוד. המפתחות נשמרים **מוצפנים** במסד.

### אותו דבר מתוך הבוט (בלי לפתוח אפליקציה)

```
/addkey gemini AIzaSy...
/addkey groq gsk_...
/providers
/testai
```

ההודעה עם המפתח נמחקת אוטומטית מהצ'אט.

### איך עובד הגיבוי בין מודלים

- הספקים נבחרים לפי **עדיפות** (מספר נמוך קודם). אפשר לשנות עם ▲▼ באפליקציה.
- בתוך ספק עם כמה מפתחות, המערכת מסובבת ביניהם (הכי פחות בשימוש קודם), וכך מכפילים את המכסה החינמית.
- שגיאת מכסה או 429: המפתח "נח" (לפי ההמתנה שהספק ביקש, או דקה ויותר) והמערכת עוברת הלאה.
- מפתח שגוי (401/403): המפתח מושבת ל-24 שעות. אפשר להחזיר ידנית עם "אפס".
- שגיאת שרת או תקלת רשת: מנוחה קצרה והמשך לבא בתור.
- רק אם **כולם** נכשלים המשתמש מקבל הודעה. האדמין רואה בהודעה מה לבדוק.

### להוסיף מודל חדש בעתיד, כל מודל שיהיה

- **ספק מוכן** (Gemini, Groq, OpenRouter, Mistral, DeepSeek, Together, OpenAI, Claude...): בוחרים מהרשימה ומדביקים מפתח.
- **כל שירות אחר שמדבר בפורמט OpenAI** (וזה כמעט כולם, כולל Ollama, LM Studio, vLLM, LiteLLM, שרת פרטי): בוחרים "מותאם אישית", כותבים שם, כתובת בסיס (למשל `https://api.something.com/v1`), שם מודל ומפתח.
- **החלפת מודל** כשמודל ישן מתבטל: בכרטיס הספק לוחצים **טען מודלים** (השרת שואל את הספק מה זמין למפתח שלך), בוחרים ו**עדכן**. מזהי המודלים משתנים מדי כמה חודשים, ולכן ברירות המחדל הן רק נקודת התחלה.

## שלב 6: להכניס קבצים לספרייה

יש שלוש דרכים, ובכולן הקובץ נשאר בטלגרם:

1. **שלח קובץ לבוט** (כאדמין). הוא נוסף לאינדקס מיד עם הודעת אישור.
2. **ערוץ פרטי**: צור ערוץ, הוסף את הבוט כ**מנהל**, והעלה אליו קבצים. כל קובץ חדש נוסף אוטומטית. זו הדרך הנוחה לספרייה גדולה, והיא תומכת בקבצים ענקיים כי אתה מעלה ישירות לטלגרם.
3. **העברה (Forward)** של הודעות קיימות מערוצים אחרים אל הבוט (כאדמין).

> קבצים שהועלו לערוץ **לפני** שהבוט נוסף אליו לא נכנסים לאינדקס אוטומטית. תעביר אותם לבוט פעם אחת.
> אם תמחק את ההודעה המקורית מהערוץ, הקובץ יפסיק להיות זמין לשליחה.

## שלב 7: למנוע מהשרת "להירדם"

ב-Render החינמי השרת נרדם אחרי כ-15 דקות בלי פעילות, וההודעה הראשונה אחר כך מתעכבת בחצי דקה.

1. הירשם חינם ל-[UptimeRobot](https://uptimerobot.com).
2. **Add New Monitor** ← סוג **HTTP(s)** ← כתובת `https://הכתובת-שלך/health` ← מרווח **5 דקות**.

## שלב 8: גיבוי, חשוב מאוד בשרתים חינמיים

בשרתים חינמיים הדיסק **נמחק בכל הפעלה מחדש**. לכן המערכת שומרת אותך מוגן:

- כל 30 דקות, אם משהו השתנה, **הבוט שולח לך קובץ גיבוי** בפרטי. המפתחות בתוכו מוצפנים.
- ידנית: `/backup`, או הכפתור "שלח לי גיבוי" במסך הניהול.
- **שחזור**: שלח לבוט את קובץ הגיבוי האחרון עם הכיתוב `/restore`. מתחדשים הספקים, המפתחות והאינדקס.
- הגיבוי מפוענח רק עם אותו `SECRET_KEY`. אם שינית אותו, המפתחות בגיבוי לא ייקראו.

(אם תרצה בעתיד שרת עם דיסק קבוע, פשוט הגדר `DATABASE_PATH` לנתיב על הדיסק.)

## שלב 9: אפליקציית אנדרואיד (APK)

**מה צריך:** מחשב עם [Node.js](https://nodejs.org) ו-[Android Studio](https://developer.android.com/studio).

```bash
./mobile/build_apk.sh https://הכתובת-שלך.onrender.com
npx cap open android        # נפתח Android Studio
```

ב-Android Studio: **Build ← Build Bundle(s)/APK(s) ← Build APK(s)**. קובץ ה-APK מופיע בתיקיית הפלט.

**כניסה באפליקציה:** מכניסים את המזהה המספרי של טלגרם ← הבוט שולח קוד בן 6 ספרות בצ'אט ← מקלידים אותו. (שלח לבוט `/start` לפחות פעם אחת קודם, אחרת הוא לא יכול לכתוב לך.) הקוד תקף ל-10 דקות, ומותר 5 ניסיונות.

## אבטחה

- בתוך טלגרם הזיהוי הוא דרך `initData` החתום, ומאומת בשרת (כולל תוקף).
- מפתחות API מוצפנים במסד, לעולם לא נשלחים חזרה ללקוח (רק 4 תווים ראשונים ואחרונים), ונמחקים מהצ'אט כשמוסיפים אותם בפקודה.
- ברירת המחדל: רק אדמינים ו-`ALLOWED_USER_IDS` יכולים להשתמש. `ALLOW_PUBLIC=true` פותח לכולם, ואז המכסות החינמיות שלך ייגמרו מהר. יש הגבלה של 20 הודעות AI לדקה למשתמש.
- ה-Webhook מוגן בכתובת סודית ובכותרת סודית.
- אל תפרסם את `SECRET_KEY` ואת `BOT_TOKEN`. אם דלפו, צור חדשים (ל-Token: `/revoke` ב-BotFather).

## הרצה מקומית ובדיקות

```bash
pip install -r requirements.txt
cp .env.example .env     # ערוך
export $(grep -v '^#' .env | xargs)
uvicorn app.main:app --reload
python -m unittest tests.test_core -v      # בדיקות לוגיקה (לא דורשות רשת)
```

להרצה מקומית מול טלגרם צריך כתובת HTTPS ציבורית (למשל `cloudflared tunnel --url http://localhost:8000`) ב-`PUBLIC_URL`.

## תקלות נפוצות

| הבעיה | הפתרון |
